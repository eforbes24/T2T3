# T2T3
Software used in "‘Loop’ tracing shows how resource self-regulation can trigger epidemic oscillations via competition between feedback levels"

T2ASI contains both the AS and ASI systems with a type II functional response. 
T3ASI contains both the AS and ASI systems with a type III functional response. 
SIZ contains both the SI and SIZ systems. 

Dynamica is required to run some functions in each notebook and should be imported for each notebook.
